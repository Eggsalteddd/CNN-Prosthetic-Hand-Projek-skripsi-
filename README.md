This repository consist of codes that are used for CNN Based gesture recognition using EMG Signal on Microcontroler

Artefacts used in this project are :
1. Arduino Nano 33 BLE Sense
2. ESP32-S3
3. ESP32-S2
4. EMG Sensor OYMotion gForce200
5. BLEtoUART module gForceJoint
6. 5x MG996R Servo
7. Voltage Stepdown Converter
8. 4x LI/ION Battery 18650
9. Inmoov robotic hand. Accesed on https://inmoov.fr/
